Installer comme application

S'installe comme une vraie application — icône, fenêtre dédiée sans barre d'adresse, pas juste un signet.
💻 Ordinateur (Chrome / Edge)
  1. Ouvre https://prodemial-nat.netlify.app.
  2. Clique sur l'icône d'installation ⊕ dans la barre d'adresse (ou menu ⋮ → « Installer Prodemial… »).
  3. Valide. Une fenêtre dédiée s'ouvre et une icône est créée sur le Bureau / dans le menu démarrer.
📱 iPhone (Safari)
  1. Ouvre cette page dans Safari (pas Chrome).
  2. Appuie sur l'icône de partage ⬆ en bas de l'écran.
  3. Choisis « Sur l'écran d'accueil ».
  4. Valide. L'icône Prodemial apparaît avec les autres applications.
🤖 Android (Chrome)
  1. Ouvre cette page dans Chrome.
  2. Appuie sur le menu ⋮ en haut à droite.
  3. Choisis « Ajouter à l'écran d'accueil » (ou « Installer l'application »).
  4. Valide. L'icône Prodemial apparaît avec les autres applications.
Les données restent propres à chaque appareil — pense à synchroniser (⟳) après avoir travaillé ailleurs.
